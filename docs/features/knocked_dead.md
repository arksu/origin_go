# Knocked state и Dead state в Haven & Hearth

**TL;DR:** в H&H два пула здоровья — SHP (мягкий, регенерирует) и HHP (жёсткий, не регенерирует сам). SHP→0 = **нокаут** (~1 минута лёжа с диалогом из 3 опций), HHP→0 = **перманентная смерть**. Труп — это тот же игровой объект с сменённой позой (`rigormortis`), а не отдельный объект; через 16–22 часа он распадается до скелета. Клиент не содержит никакой логики нокаута/смерти — всё состояние живёт на сервере и передаётся клиенту сменой поз.

## Модель здоровья

- **SHP** — «мягкие» хиты, основной пул урона. Медленно регенерирует только при высокой сытости (energy). SHP = 0 → нокаут.
- **HHP** — «физическая жизнеспособность». Падает от ран (wounds) и **grievous damage** (≈40% урона оружием идёт в HHP). Не регенерирует сама — лечится только перевязкой ран. HHP = 0 → смерть.
- **MHP = 100·√(CON/10)** — размер пулов от Конституции.

Формула PvP-убийства (W16): *Chip* (до 40% MHP в HHP без нокаута) + *Max Hit* (удар ≥100% остатка HP → 40% MHP) + *Concussion* (при каждом нокауте случайная рана 5–20% MHP) = максимум 100%. То есть убить «с одного нокаута» нельзя — нужно минимум два захода урона, и при манёврах жертвы «защита нокаута» не гарантируется (loftar: *«it is at the very least a 'two-hit'»*).

## Knocked state

**Триггер:** SHP падает до 0 (игроки, животные, обвалы в шахтах, пиявки). Голод и утопление нокаута не дают — они бьют сразу по HHP.

**Что происходит (с патча «Iced Bait», 2021):** у лежащего открывается диалог из трёх опций:
1. **Travel to Hearth Fire** (выбрано по умолчанию) — через **30 секунд** автопорт домой;
2. **Log out** — логаут где лежишь (нельзя, если ты outlaw);
3. **Remain in place** — через **~50–60 секунд** персонаж сам встаёт с **1 SHP**.

Нельзя двигаться, действовать, фаять (если red-handed/outlaw/в данжене/в глубокой воде). Hearth fire разрушен → автоматически выбран пункт 3.

**Что могут делать другие игроки с лежащим:**
- **Лутать** — нужен скилл **Theft** (50k LP): инвентарь, экипировка, study-предметы. Это преступление (запах Reek of Theft, ищется по следу).
- **Бить/добивать — нельзя**: с W10 действует **Knockout Protection** (серверное правило, в клиенте его следов нет). Обойти можно только скиллом **Murder**: бафф **Murderous Rage** (+20% grievous damage, 24 часа) снимает защиту с самого разъярённого — то есть убить можно только того, кто сам агрился или агрится сейчас.
- **Саботировать**: подбросить пиявки в слоты (обычный SHP-урон пиявок в нокауте конвертируется в HHP), снять CON-экипировку (MHP падает — можно убить), разбить лодку под лежащим в глубокой воде.
- **Носить тело**: в вики это не документировано, но в коде клиента есть поза `carried` (относится к «лежачему» семейству) и механизм `OD_FOLLOW` — переноска безвольных тел в современном клиенте существует.
- Оживить/разбудить раньше — **нельзя**.

**Животные** не уважают Knockout Protection: у каждого из них ролл «дизейнджнуться» при ударе по лежачему; волки, кабаны, медведи, рыси, тролли и т.д. могут добить.

## Dead state

**Труп** — **тот же gob игрока** с позой `rigormortis` (в воде — `drowned`/`waterdead`, позже `deadskeletonpose`). Отдельного объекта-трупа нет, в отличие от туш животных (`animalcarcass`). Лутается через flower-menu «Steal». Через **16–22 реальных часа** труп распадается до скелета (его уже можно поднять и положить в повозку), нелутанное выпадает на землю. У очага погибшего при смерти идёт «черепной дым». Труп можно закопать целиком (с 2021) или по частям.

**Смерть перманентная**: респавна того же персонажа нет. Создаётся новый персонаж-**наследник** (descendant) через рунный камень на кладбище, спавнится у **hearth fire предка** (или Thingwall с W15). Наследование потраченных FEPs/LP: **базово 15%**, +10% за погребённый череп, +20% за скелет → **максимум 45%** (в W16 Combat Guide фигурирует 60% — конфликт источников не разрешён). Голод наследуется от предка (фикс «Hungercide», 2023).

**Сопутствующее:** нокаут = преступление «Battery» (запах, но не капитальное), убийство = «Murder» (outlaw-таймер 3× больше), по запахам преступлений можно крафтить **Nidbane** — духа-мстителя с фактором преступления (theft 0.3 / battery 0.6 / murder 1.2).

## Реализация в коде клиента

Официальный клиент открыт ([dolda2000/hafen-client](https://github.com/dolda2000/hafen-client) — зеркало `git://sh.seatribe.se/hafen-client`). Ключевые находки (проверено по исходникам, включая форк [Nightdawg/Hurricane](https://github.com/Nightdawg/Hurricane) с явной детекцией):

- В стоковом клиенте **ноль** кода со словами knock/corpse/unconscious — клиент state-agnostic. Сервер гоняет состояние двумя.generic-дельтами по gob: **`OD_CMPPOSE=16`** (списки поз `$cmppose`, временные позы с длительностью `ttime` в десятых секунды) и **`OD_CMPEQU=18`**.
- **Позы:** `knock` (нокаут), `rigormortis`/`drowned`/`waterdead`/`deadskeletonpose` (смерть), `carried` (тело несут). Форк Hurricane детектит «лежачее» семейство просто по substring: `contains("knock") || contains("dead") || ... || contains("carried")`.
- **Дискриминатор «нокаут vs смерть»**: поза `rigormortis` = мёртв; поза `knock`/`drowned` без надетого предмета `knockchirp` = мёртвый игрок (knockchirp вешается только на нокаутнутых существ).
- **`OD_HEALTH=14`**: байт 0–4 на gob → красный тинт/трещины на модели (индикатор урона тела, не флаг нокаута).
- **Носка тел:** `OD_FOLLOW=10` — переносимый gob позиционируется на bone-offset носильщика.
- Лут лежачего — цветочное меню **«Steal»** по клику на gob (в Hurricane даже хоткей «Loot Nearest Knocked Player»).
- Никакого «You are unconscious»/чёрного экрана в клиенте нет — только серверные строки через `uimsg`, прогресс-бар и метры (`getmeter("hp")`).
- **Тайминги сервера публично нигде не существуют** — серверных эмуляторов H&H нет вообще. Единственные числа — из вики (~1 мин, порт на 30-й секунде) и комментария в Hurricane: *«~50 seconds to get up, can port or log out after 25–30»*.

## Сравнение с origin_go

В origin_go используются SHP/HHP/MHP с `MHP = √CON·25`, KO при SHP≤0 и смерть при HHP≤0 ([health.go](/Users/park/projects/origin_go/internal/entityhealth/health.go)). Реализованный KO длится обязательные 60 секунд в runtime; затем персонаж остаётся лежать до добровольного подъёма. Поза сохраняется в БД и видна наблюдателям. Немодальное окно находится поверх игровых окон и разрешает ввод за его пределами. KO блокирует только предметные операции инициатора; движение и остальные действия подчиняются прежним правилам. Самостоятельный stun независим. Подробный контракт, рестарт, восстановление и необходимые изменения протокола описаны в [runtime_ko.md](runtime_ko.md).

Перманентная смерть по-прежнему конвертирует сущность в `player_death`, удаляет персонажа из БД и показывает DeathDialog ([player_death_system.go](/Users/park/projects/origin_go/internal/game/player_death_system.go), [shard.go](/Users/park/projects/origin_go/internal/game/shard.go)).

Найденные гэпы относительно H&H:
1. **Hearth Fire, выход из боя и новая модель урона** остаются отдельными задачами; автоматический подъём не входит в текущий этап.
2. **Нет Knockout Protection / Theft-гейтинга** на атаку и лут лежачих.
3. **Нет распада трупа→скелета, погребения и системы наследования** (15–45%).
4. Нет сплита урона на grievous/concussion (у нас soft/hard есть, а вот «раны» и ролл сотрясения при KO — нет).
